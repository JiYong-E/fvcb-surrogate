# Reference solver

The coupled C3 reference model is the open-source **LeafGasExchange.jl**,
https://github.com/cropbox/LeafGasExchange.jl , used as `LeafGasExchange.ModelC3BB`
(FvCB photosynthesis + Ball-Berry stomatal conductance + leaf energy balance).
The commit is pinned in `02_features/Manifest.toml` (the code that actually calls it).
